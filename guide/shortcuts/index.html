Keyboard shortcuts

Noteic is made for the pen, but these keys save time when a keyboard is attached.

Files#

Ctrl+NNew document
Ctrl+OOpen
Ctrl+SSave
Ctrl+Shift+SSave as

Editing#

Ctrl+ZUndo
Ctrl+YRedo
Ctrl+X, Ctrl+C, Ctrl+VCut, copy, paste
Ctrl+Shift+VPaste at the same position as the original
Ctrl+DDuplicate the selection
Ctrl+ASelect everything on the page
DeleteDelete the selection
EscClear the selection, leave the Pan tool, cancel a polygon
Ctrl+KAnchor link for the selection, or a link in text
ShiftWhile drawing shapes: 45°, squares and circles. While rotating: 15° steps

View and pages#

Ctrl++, Ctrl+-Zoom in, zoom out
Ctrl+0Zoom to 100%
Space + dragMove the view with any tool
Page Up, Page DownPrevious and next page
Ctrl+Home, Ctrl+EndFirst and last page
Ctrl+GPage overview
Ctrl+LShow or hide the ruler or protractor
Ctrl+BLibrary (in a text box: bold)
F11Full screen

Tabs#

Ctrl+TabTab you used last
Ctrl+Page Down, Ctrl+Page UpNext and previous tab
Ctrl+WClose the tab

Text boxes#

Ctrl+B, Ctrl+I, Ctrl+UBold, italic, underline
Tab, Shift+TabIndent lists; in tables, next and previous cell
EscClose the text box
Ctrl+EnterInsert the formula (in the formula editor)
